# W11 — Windows 11 в браузере

Проект поднимает полноценную виртуальную Windows 11 в Docker с доступом через браузер (noVNC) и, при необходимости, через RDP. Основа — образ `dockurr/windows`.

> **Важно:** этот репозиторий содержит конфигурацию запуска, а не готовый образ Windows. Первый старт скачивает установочные файлы и может занять 5–20 минут. Нужен компьютер/сервер с Docker, достаточной RAM и диском. GitHub Codespaces может не поддерживать аппаратную виртуализацию KVM, поэтому запуск там не гарантирован.

## Быстрый запуск

1. Установи Docker Engine + Docker Compose plugin.
2. Скопируй пример настроек:
   ```bash
   cp .env.example .env
   ```
3. Открой `.env` и задай свой пароль. Не публикуй этот файл и не добавляй реальные пароли в Git.
4. Запусти виртуальную машину:
   ```bash
   docker compose up -d
   ```
5. Открой в браузере `http://localhost:8006`. Для подключения по RDP используй `localhost:3389`, если RDP-клиент настроен.

## Требования

- Docker Engine и Docker Compose v2
- Рекомендуется 8 ГБ RAM (выделяется 6 ГБ по умолчанию) и 50+ ГБ свободного места
- Для лучшей скорости на Linux рекомендуется KVM и доступ к `/dev/kvm`
- Стабильное интернет-соединение для первоначальной загрузки Windows

## Настройки

Параметры находятся в `.env`:

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `WINDOWS_VERSION` | `11` | Версия Windows |
| `WINDOWS_USERNAME` | `winuser` | Локальный пользователь |
| `WINDOWS_PASSWORD` | задаётся вручную | Пароль пользователя |
| `RAM_SIZE` | `6G` | Память виртуальной машины |
| `CPU_CORES` | `4` | Число виртуальных ядер |
| `DISK_SIZE` | `64G` | Размер виртуального диска |

## Управление

```bash
docker compose logs -f windows  # смотреть логи
docker compose stop             # остановить VM, сохранив данные
docker compose start            # запустить снова
docker compose down             # удалить контейнер, но сохранить именованный том
docker compose down -v          # удалить контейнер И данные Windows без возможности восстановления
```

Данные Windows сохраняются в Docker-томе `windows-data`. Команда `down -v` удаляет этот том и все файлы внутри.

## Безопасность

- Не публикуй порты 8006/3389 в открытый интернет без VPN или дополнительной защиты.
- Используй уникальный пароль и держи файл `.env` локально.
- Убедись, что у тебя есть право использовать выбранную редакцию Windows и соблюдай условия лицензии Microsoft.
- Контейнер виртуализирует Windows; это не заменяет установку Windows на физический компьютер.
